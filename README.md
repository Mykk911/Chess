# 2D Chess App vs AI

Простое 2D веб-приложение с шахматами против ИИ.

## Возможности

- Графическая 2D-доска (клики мышкой)
- Игра против ИИ
- Уровни ИИ: `100`, `500`, `1000`, `1500`, `2000`
- Выбор цвета: белые/чёрные

## Установка

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

## Запуск

```bash
python3 app.py
```

Открой в браузере: `http://localhost:8000`

## Как играть

1. Выбери уровень и цвет.
2. Нажми **Новая игра**.
3. Кликни по своей фигуре, затем по клетке назначения.
