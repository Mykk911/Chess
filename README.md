# 2D Шахматы с ИИ (веб‑приложение)

Это простые шахматы с 2D‑графикой и ботом.

## Возможности

- 2D доска в браузере (клики мышкой).
- Уровни ИИ: `100`, `500`, `1000`, `1500`, `2000`.
- Выбор цвета игрока (белые/чёрные).
- Валидация легальных ходов и автоматический ответ бота.

## Установка

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

## Запуск

```bash
python3 app.py
```

Открой в браузере: `http://localhost:8000`
